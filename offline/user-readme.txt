BUMPMESH OFFLINE EDITION
========================

This is BumpMesh (bumpmesh.com) packaged so it runs on a PC with no internet
connection. Everything it needs is in this folder. The program itself never
downloads anything and never sends your files anywhere. The shop and donate
links in the page only open if you click them.


HOW TO START IT

1. Copy the whole folder you unzipped to the PC. The Desktop or Documents is fine.
2. Double click the file named START BumpMesh.bat
3. A black window says BumpMesh is running, and your browser opens by itself.
Leave the black window open while you use BumpMesh.


HOW TO STOP IT

Close the black window. Closing only the browser tab does not stop it.


IF THE BROWSER DOES NOT OPEN

Type this into the address bar of your browser   127.0.0.1:8731
If it shows nothing, use the address on the line of the black window that
starts with the word Address. The number at the end may be 8732, 8733 and so
on if another program is already using 8731.


IF WINDOWS SHOWS A BLUE WINDOWS PROTECTED YOUR PC BOX

The program is not signed by a big publisher. Click More info, then click Run
anyway. The program only talks to your own browser on this PC (127.0.0.1).


WHAT YOU CAN OPEN

STL, OBJ, 3MF and STEP files all open. All the textures are included, and you
can export STL and 3MF files. Exported models go to your normal Downloads folder.


WHAT IS IN THIS FOLDER

START BumpMesh.bat    The file you double click.
bumpmesh-server.exe   The small program that hands the files to your browser.
app                   BumpMesh itself, the textures and the 3D libraries.
server-source         The source code of bumpmesh-server.exe.
