WHAT WAS CHANGED FROM THE ORIGINAL VERSION 1.4.3

Every change is a commit on the offline build branch, so the full list is
always available with the command  git diff a6d6d6e offline-build  or in the
GitHub compare view. The commit a6d6d6e is the original version 1.4.3.
The changes, all made on October 23, 2026, are these.
  * index.html. The web library addresses (three.js and fflate) now point at the
    local vendor folder. The CDN preconnect hint was removed. The header and
    source links say this is an unofficial build. The page title was changed.
    The canonical and Open Graph URL tags that claim bumpmesh.com were removed. The
    Source code line in the Licence popup also names this build's repository.
  * js/threeCompat.js. The path the workers use to load three.js points at vendor.
  * js/stepWorker.js. The import address of the STEP reader (meshStep 0.1.0) now
    points at vendor/meshstep instead of the jsDelivr CDN. Same release, unmodified.
  * The Imprint and Privacy popup was replaced by an About this unofficial
    build notice. The original names Stefan Hermann as the operator of the
    official website, which is not true of this build. The change was made in
    index.html and in all 16 language files in js/i18n.
  * The CNAME file was removed so that turning on GitHub Pages cannot claim
    bumpmesh.com.
  * changelog.html. The canonical and Open Graph URL tags were removed, the title was
    marked unofficial, and a dated note was added to the header comment.
  * The folders vendor and offline were added, and so was the file .gitattributes.
    The README.md file was replaced by an offline build README. The original is
    kept as README-upstream.md.
Nothing else in BumpMesh was changed.
