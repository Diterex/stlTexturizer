WHAT WAS CHANGED FROM UPSTREAM v1.4.3
-------------------------------------
Every change is a commit on the offline-build branch, so the full list is
always available with:  git diff a6d6d6e offline-build   (a6d6d6e = upstream v1.4.3; or the GitHub compare
view). Summary, all made 2026-10-23:
  * index.html: the web-library addresses (three.js, fflate) now point at the
    local vendor/ folder; the CDN preconnect hint was removed; the header and
    source links say this is an unofficial build; the page title is changed and the
    canonical/og:url tags that claim bumpmesh.com are removed; the Source code line in the
    Licence popup also names this build's repository.
  * js/threeCompat.js: the path workers use to load three.js points at vendor/.
  * js/stepWorker.js: the import address of the STEP reader (meshStep 0.1.0) now
    points at vendor/meshstep instead of the jsDelivr CDN. Same release, unmodified.
  * The Imprint and Privacy popup was replaced by an "About this unofficial
    build" notice. The original names Stefan Hermann as the operator of the
    official website, which is not true of this build. The change was made in
    index.html and in all 16 language files in js/i18n/.
  * CNAME removed so that enabling GitHub Pages cannot claim bumpmesh.com.
  * js/i18n/*.js: the removed Imprint keys; changelog.html: canonical/og:url removed,
    title marked unofficial, dated note in the header comment.
  * vendor/ added (three, fflate, meshstep); offline/ added; .gitattributes added; README.md replaced by an
    offline-build README (the original is kept as README-upstream.md).
Nothing else in BumpMesh was changed.
